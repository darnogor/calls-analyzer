# Документация

Черновик 0.2 от 2026-10-13.

В 0.1 система была продолжением amoCRM. В 0.2 ядро принимает звонок в едином формате, а конкретная CRM живёт в отдельном плагине. Проект — единица данных и настроек анализа. Ручная загрузка работает без CRM.

| Документ | О чём |
| --- | --- |
| [product.md](product.md) | Задача, проект, экраны ядра, граница с плагином |
| [architecture.md](architecture.md) | Контейнеры ядра, конвейер, очереди |
| [intake.md](intake.md) | Единственный формат, которым звонок входит в ядро |
| [data-model.md](data-model.md) | Таблицы ядра. Таблиц CRM здесь нет |
| [services/](services/README.md) | Контейнеры ядра: вход и выход |
| [plugins/](plugins/README.md) | Контракт плагина и плагин amoCRM |
| [assumptions.md](assumptions.md) | Решения, принятые до ответов на открытые вопросы |
| [open-questions.md](open-questions.md) | Что нужно подтвердить до кода |

Порядок чтения: продукт → архитектура → контракт приёма → сервис, который смотрите. Плагин amoCRM читать после контракта приёма. Модель данных — когда нужны поля.
