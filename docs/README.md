# Документация

Контракты ядра зафиксированы. Кода ещё нет. Единственный открытый пункт — чеклист одного живого звонка amoCRM в [open-questions.md](open-questions.md). Пока он не пройден, код плагина amoCRM не пишем. Имена провайдеров речи и оценки выбираются позже и ядро не блокируют.

Ядро принимает звонок в едином формате. Конкретная CRM живёт в отдельном плагине. Проект — единица данных и настроек анализа. Ручная загрузка работает без CRM.
