# Открытые вопросы

Ответ меняет черновик. Ниже остался чеклист одного реального звонка. Пока он не пройден, код плагина amoCRM не пишем.

Зафиксировано: роли, внешние API без локальных моделей, TypeScript, пять этапов, плеер через `api`, менеджер по продажам читает весь проект, отдельный список проблем, без CSV и без оценки текста, фильтр стадий — стадия сделки, поиск по контакту, компании, телефону, менеджеру и сделке, один Docker-сервер со всеми контейнерами, часовой пояс нового проекта — Москва, кнопка обновления amoCRM — на странице плагина, отдельного признака «следующий шаг» модель не возвращает. Имена провайдеров речи и оценки выбираются позже. Экрана добавочных номеров нет, пока живой звонок не покажет, что он нужен.

## 7. Телефония в плагине amoCRM

На одном реальном звонке нужно проверить:

1. Где появляется `call_in` / `call_out`.
2. Приходят ли `uniq`, `duration`, ответственный и `link`.
3. Можно ли скачать запись без браузерной сессии.
4. Есть ли у ссылки срок жизни.
5. Родитель примечания: контакт, сделка или компания.
6. Через сколько секунд после разговора примечание и ссылка появляются в amoCRM.

Пока это неизвестно, плагин либо передаёт в ядро обычный URL, либо скачивает файл сам и шлёт байты. Отдельного способа «телефония» у `media` больше нет.
