# Допущения черновика 0.2

Решения, на которых держатся контракты, пока открыты [вопросы](open-questions.md). Кода ещё нет: меняется документ.

| # | Допущение | Куда смотреть |
| --- | --- | --- |
| A1 | Установка содержит много проектов. Данные проекта изолированы `project_id`. Проект может обойтись без CRM. | [product.md](product.md) |
| A2 | Вход пользователей пока не проектируем. API доступен внутри контура. Создание источника требует того же доступа. | [product.md](product.md), [services/api.md](services/api.md) |
| A3 | Сервисы ядра передают работу через Redis. База ядра одна. Плагин пишет только по HTTP и в свою базу. | [architecture.md](architecture.md) |
| A4 | Язык реализации не выбран. Контракты — HTTP и сообщения очереди. Redis остаётся транспортом очереди. | [architecture.md](architecture.md) |
| A5 | Файл по URL ядро копирует в хранилище. Файл с формы пишет `api`. Если URL требует секрет CRM или телефонии, источник скачивает файл сам и присылает байты. | [intake.md](intake.md), [services/media.md](services/media.md) |
| A6 | Речевой движок и LLM спрятаны за `transcriber` и `analyzer`. На границе виден JSON. | [services/transcriber.md](services/transcriber.md), [services/analyzer.md](services/analyzer.md) |
| A7 | Итог считает `analyzer` по весам снимка карточки проекта. Модель возвращает оценки этапов, комментарии и краткий вывод. | [services/analyzer.md](services/analyzer.md) |
| A8 | Новый проект получает пять этапов продажи с весами 15 / 30 / 20 / 20 / 15. Карточку можно заменить. Готовые звонки не пересчитываются. | [product.md](product.md) |
| A9 | Известная длительность ниже порога отклоняется ответом `422`, строки нет. Длительность, выясненная из файла, оставляет строку `skipped_short` без анализа. | [intake.md](intake.md) |
| A10 | Главная таблица показывает только `completed`. | [services/api.md](services/api.md) |
| A11 | Фильтр стадий — точное совпадение с `current_deal_status_name`. Поиск — имя контакта, компания, телефон. | [services/api.md](services/api.md) |
| A12 | Часовой пояс нового проекта — `Europe/Moscow`. Его можно сменить в настройках проекта. | [data-model.md](data-model.md) |
| A13 | К проекту можно подключить несколько плагинов. Ручной источник есть всегда. | [product.md](product.md) |
| A14 | Колонки таблицы следуют текущей карточке. Карточка звонка показывает снимок этапов того анализа. | [product.md](product.md) |
| A15 | Язык распознавания берётся из проекта, по умолчанию `ru`. | [services/transcriber.md](services/transcriber.md) |
| A16 | Параллельность распознавания и оценки — настройка контейнера, старт по 2. | [architecture.md](architecture.md) |
| A17 | Снаружи опубликован только `ingress`. | [architecture.md](architecture.md) |
| A18 | Первый и пока единственный описанный плагин — amoCRM. Опрос, импорт истории, повторы чтения записи и словарь добавочных принадлежат ему. | [plugins/amocrm.md](plugins/amocrm.md) |
