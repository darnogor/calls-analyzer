# Сервисы

Каждый прикладной контейнер описан отдельно. Вход и выход указаны полностью в его файле. Общая схема очередей и статусов — в [архитектуре](../architecture.md). Поля базы — в [модели данных](../data-model.md).

| Сервис | Файл | Вход | Выход |
| --- | --- | --- | --- |
| `web` | [web.md](web.md) | действия руководителя и JSON `api` | запросы к `api`, переход в amoCRM |
| `api` | [api.md](api.md) | HTTP экранов | JSON экранов, настройки, команда синхронизации |
| `crm-sync` | [crm-sync.md](crm-sync.md) | webhook, опрос, команды, ответы amoCRM | строки звонков и справочников, задание на запись |
| `media` | [media.md](media.md) | задание и файл по URL | объект в хранилище, задание на транскрипцию |
| `transcriber` | [transcriber.md](transcriber.md) | задание и аудиофайл | транскрипт, задание на оценку |
| `analyzer` | [analyzer.md](analyzer.md) | задание, транскрипт, контекст сделки | оценки, комментарии, итог |

Инфраструктурные контейнеры `ingress`, `postgres`, `redis`, `minio` описаны в [архитектуре](../architecture.md).
