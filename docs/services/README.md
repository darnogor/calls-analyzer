# Сервисы ядра

Каждый контейнер ядра описан отдельно. Общая схема очередей — в [архитектуре](../architecture.md). Формат входящего звонка — в [контракте приёма](../intake.md). Поля базы — в [модели данных](../data-model.md).

Плагины в эту таблицу не входят. Они описаны в [plugins/](../plugins/README.md).

| Сервис | Файл | Вход | Выход |
| --- | --- | --- | --- |
| `web` | [web.md](web.md) | действия человека и JSON `api` | запросы к `api`, переход по готовому внешнему адресу |
| `api` | [api.md](api.md) | HTTP экранов и контракт приёма | JSON экранов, настройки проекта, задание на файл |
| `media` | [media.md](media.md) | задание с URL или уже лежащим файлом | объект в хранилище, задание на транскрипцию |
| `transcriber` | [transcriber.md](transcriber.md) | задание и аудиофайл | транскрипт, задание на оценку |
| `analyzer` | [analyzer.md](analyzer.md) | транскрипт, карточка, промпт и факты | снимок оценок, покрытие и итог |
