# Сервис `web`

Контейнер со статическим интерфейсом. Собирается в файлы и отдаётся браузеру. К amoCRM, базе, очередям и хранилищу файлов не обращается.

## Результат

Четыре рабочих экрана и экран настроек из [продукта](../product.md).

## Вход

1. Действия пользователя: открытие адреса, фильтры, сортировка, клик по строке, клик по таймкоду, кнопки плеера, сохранение настроек, «Обновить данные», «Подключить amoCRM».
2. Ответы `api`, перечисленные в [api.md](api.md).
3. Файл записи по короткой ссылке, которую выдал `api`. Файл воспроизводит браузер напрямую из хранилища по этой ссылке.

Адресная строка — часть входа. Фильтры и сортировка читаются из query при открытии ссылки.

```text
/calls?manager={manager_id}&date_from=2026-10-05&date_to=2026-10-05&q=&deal_status_id=&sort=objections_score&order=asc&page=1
/calls/{call_id}
/managers?date_from=2026-10-05&date_to=2026-10-05&sort=overall_score&order=asc
/managers/{amo_user_id}?date_from=2026-10-05&date_to=2026-10-05
/settings
```

Период по умолчанию на «Звонках» и «Менеджерах» — текущие сутки в часовом поясе из настроек. Пока в допущениях это `Europe/Moscow`.

## Выход

Запросы к `api`:

| Действие на экране | Запрос |
| --- | --- |
| Открыть список звонков | `GET /api/calls` |
| Открыть карточку звонка | `GET /api/calls/{id}` |
| Включить запись | `GET /api/calls/{id}/recording` |
| Открыть список менеджеров | `GET /api/managers` |
| Открыть карточку менеджера | `GET /api/managers/{amo_user_id}` и `GET /api/managers/{amo_user_id}/calls` |
| Заполнить фильтр менеджеров и стадий | `GET /api/filters` |
| Открыть настройки | `GET /api/settings` и `GET /api/integration` |
| Сохранить порог и веса | `PUT /api/settings` |
| Обновить данные из amoCRM | `POST /api/sync` |
| Подключить amoCRM | переход браузера на `/oauth/amocrm/start` |

Переход в amoCRM — это обычная ссылка `target=_blank` на `amo_url`, который уже пришёл в JSON. Отдельного запроса нашего сервера для этого нет.

Клик по таймкоду меняет только положение плеера в браузере. На сервер ничего не уходит.

Цвет оценки считается в браузере по числу из JSON: 80–100 зелёный, 60–79 жёлтый, 0–59 красный.

## Что остаётся другим сервисам

Список, карточка, средние оценки и подпись ссылки на файл приходят готовыми из `api`. `web` не вычисляет средние и не собирает URL amoCRM сам, кроме отображения уже готового `amo_url`.
