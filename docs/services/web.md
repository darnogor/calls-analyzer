# Сервис `web`

Статический интерфейс ядра. В CRM, базу, очереди и хранилище сам не ходит. Подключение amoCRM не рисует: в настройках проекта стоит ссылка на страницу плагина, если такой источник создают.

## Результат

Экраны из [продукта](../product.md): вход, аккаунты, список проектов, звонки, загрузка, карточка звонка, менеджеры, карточка менеджера, настройки проекта.

## Вход

1. Действия человека: смена проекта, фильтры, сортировка, клик по строке, таймкод, плеер, форма загрузки, сохранение карточки оценки.
2. Ответы `api` из [api.md](api.md).
3. Файл записи ответом `api`. Его воспроизводит браузер. Адрес хранилища в страницу не попадает.

Адреса:

```text
/login
/accounts
/
/p/{project_id}/calls?manager={manager_id}&date_from=2026-10-13&date_to=2026-10-13&q=&deal_status=&sort=stage.objections&order=asc&page=1
/p/{project_id}/calls/new
/p/{project_id}/calls/{call_id}
/p/{project_id}/problems
/p/{project_id}/progress
/p/{project_id}/managers?date_from=2026-10-13&date_to=2026-10-13&sort=overall&order=asc
/p/{project_id}/managers/{manager_id}
/p/{project_id}/settings
/p/{project_id}/inputs
```

Период по умолчанию на «Звонках» и «Менеджерах» — текущие сутки в часовом поясе проекта.

Форма «Новый звонок» собирает файл, дату, менеджера, телефон, направление, контакт, компанию, название сделки, стадию на момент звонка, заметку и произвольные поля. Эти поля остаются на карточке и могут фильтровать список. Менеджера выбирают из списка проекта или вписывают новое имя.

## Выход

| Действие | Запрос |
| --- | --- |
| Войти | `POST /api/session` |
| Выйти | `DELETE /api/session` |
| Понять, кто вошёл и какие у него проекты | `GET /api/me` |
| Открыть список аккаунтов | `GET /api/accounts` |
| Создать аккаунт | `POST /api/accounts` |
| Выключить аккаунт или задать новый пароль | `PATCH /api/accounts/{account_id}` |
| Назначить роли в проектах | `PUT /api/accounts/{account_id}/projects` |
| Открыть список проектов | `GET /api/projects` |
| Создать проект | `POST /api/projects` |
| Открыть список звонков | `GET /api/projects/{project_id}/calls` |
| Открыть карточку | `GET /api/projects/{project_id}/calls/{id}` |
| Включить запись | `GET /api/projects/{project_id}/calls/{id}/recording`, ответ с байтами файла |
| Открыть проблемы обработки | `GET /api/projects/{project_id}/calls?view=problems` |
| Открыть звонки в работе | `GET /api/projects/{project_id}/calls?view=progress` |
| Загрузить звонок | `POST /api/projects/{project_id}/calls` как `multipart` |
| Список менеджеров | `GET /api/projects/{project_id}/managers` |
| Карточка менеджера | `GET /api/projects/{project_id}/managers/{manager_id}` и `GET .../managers/{manager_id}/calls` |
| Фильтры и заголовки колонок | `GET /api/projects/{project_id}/filters` |
| Промпты | `GET /api/projects/{project_id}/settings` |
| Сохранить промпт, порог и часовой пояс | `PUT /api/projects/{project_id}/settings` |
| Список скриптов | `GET /api/projects/{project_id}/inputs` |
| Сохранить скрипт | `POST /api/projects/{project_id}/inputs` |
| Источники | `GET /api/projects/{project_id}/sources` |
| Выпустить код подключения источника | `POST /api/projects/{project_id}/sources` |
| Переименовать ручного менеджера | `PATCH /api/projects/{project_id}/managers/{manager_id}` |

Администратор видит все действия. Руководитель видит загрузку звонка, произвольные поля, скрипты, источники и правку имени ручного участника. Кнопки проектов, аккаунтов и промптов у руководителя скрыты. Менеджер по продажам видит все готовые звонки проекта, карточки разговоров, сводку участников и плеер. Список проблем и список звонков в работе ему не показывают.

После выпуска кода браузер открывает `/plugins/amocrm/connect?setup_code={code}`, когда выбран поставщик `amocrm`. Другой поставщик откроет свой префикс. Страницу OAuth рисует плагин.

Внешний адрес контакта или сделки — ссылка `target=_blank` на `external_url` из JSON. Пустой адрес остаётся текстом. Ядро и `web` адрес не собирают.

Клик по таймкоду двигает только плеер.

Цвет ячейки считается в браузере: 80–100 зелёный, 60–79 жёлтый, 0–59 красный. Заголовки колонок этапов берутся из `filters.stages` текущей карточки. Значение ячейки ищется в массиве оценок строки по `key`. На карточке звонка формулировка этапа берётся из `instruction` снимка этого звонка, не из текущих настроек. Фильтр `deal_status` — стадия сделки. Пункт без фильтра подписан «Все стадии». «Этапы» на этом фильтре не пишутся.

`error.message` на экране не показывается как есть. Браузер подставляет русский текст:

| Код | Текст |
| --- | --- |
| `empty_transcript` | Пустой ответ распознавания |
| `transcript_missing` | Нет транскрипта |
| `invalid_model_json` | Ответ модели не разобран |
| `provider_unavailable` | Провайдер распознавания недоступен |
| `model_unavailable` | Модель недоступна |
| `audio_network_failure` | Не удалось скачать запись |
| `audio_object_missing` | Файла нет в хранилище |

Ответ загрузки содержит id звонка. Форма открывает его карточку. Если файл короче порога, карточка показывает `skipped_short`. Если длительность прочитать нельзя, карточка показывает `skipped_no_duration`. В таблицу готовых звонков эти строки не входят.
