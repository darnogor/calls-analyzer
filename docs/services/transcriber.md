# Сервис `transcriber`

Превращает файл в реплики с ролями и таймкодами. Оценку не ставит. Во внешние системы проекта, кроме провайдера распознавания, не ходит.

Провайдер задаётся окружением контейнера (`STT_PROVIDER`, ключ). Язык берётся из `projects.language` этого звонка. Пока вопрос о провайдере открыт, в конфигурации языка проекта по умолчанию стоит `ru`.

Роли: две дорожки стерео — левая `manager`, правая `client`, если провайдер отдаёт каналы отдельно. Одна дорожка — провайдер помечает говорящих, первый говорящий в исходящем звонке считается менеджером, во входящем клиентом. При пустом `direction` первый говорящий считается менеджером. Если говорящих больше двух, остальные реплики помечаются `client`. В сохранённом JSON допустимы только `manager` и `client`.

## Вход

Очередь `calls.transcribe`:

```json
{
  "message_id": "uuid",
  "project_id": "uuid",
  "call_id": "uuid",
  "attempt": 1,
  "enqueued_at": "2026-10-13T12:02:00+03:00",
  "audio": {
    "bucket": "recordings",
    "key": "projects/p1/calls/58374.mp3",
    "content_type": "audio/mpeg"
  }
}
```

Сервис читает объект из `minio`, у звонка — `direction`, у проекта — `language`. Если `call_analysis.transcript_json` уже заполнен, распознавание не повторяется и сразу публикуется выход.

В начале работы статус `transcribing`. Строка `call_analysis` создаётся, если её ещё нет, и пока хранит только `call_id`.

Одновременно выполняется не больше `TRANSCRIBE_CONCURRENCY` заданий. Стартовое значение — 2.

## Выход

`call_analysis.transcript_json`:

```json
[
  {
    "speaker": "manager",
    "start": 0.0,
    "end": 4.5,
    "text": "Добрый день, Алексей..."
  },
  {
    "speaker": "client",
    "start": 4.6,
    "end": 8.1,
    "text": "Да, здравствуйте..."
  }
]
```

Требования: порядок по `start`, `end` больше `start`, `text` без пустых строк, роли только `manager` и `client`, время в секундах от начала файла.

Оценки и `summary` этот сервис не заполняет.

Сообщение `calls.analyze`:

```json
{
  "message_id": "uuid",
  "project_id": "uuid",
  "call_id": "uuid",
  "attempt": 1,
  "enqueued_at": "2026-10-13T12:06:00+03:00"
}
```

Текста в очереди нет. Его прочитает `analyzer` из базы.

## Ошибки

| Ситуация | Результат |
| --- | --- |
| файла нет в хранилище | повтор, затем `failed`, `error.stage=transcribe` |
| провайдер недоступен или вернул ошибку | повтор, затем `failed` |
| ноль реплик | повтор, затем `failed`, `error.message=empty_transcript` |

Реплики с успешно расставленными по правилу выше ролями считаются нормальным выходом. Статус `completed` ставит `analyzer`.
